OmniVoice sul PC

OmniVoice (ora si chiama VoiceStudio) è l’app per Windows per clonare voci, dettare, doppiare e creare audio in italiano e in centinaia di altre lingue. Funziona sul computer, senza abbonamento.

Scarica OmniVoice per Windows
File ufficiale: VoiceStudio_0.5.0_x64_en-US.msi · circa 160 MB
  1. Scarica il file con il pulsante verde.
  2. Aprilo e completa l’installazione (Avanti / Next).
  3. Nel menu Start cerca VoiceStudio oppure OmniVoice.

Serve circa 10 GB liberi sul disco: al primo avvio l’app scarica i modelli vocali. La scheda video NVIDIA è utile ma non obbligatoria (senza GPU è più lento).

Se preferisci l’installazione automatica, scarica anche Installa-OmniVoice.bat e Installa-OmniVoice.ps1 nella stessa cartella, poi fai doppio clic sul file .bat.
