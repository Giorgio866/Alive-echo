# OmniVoice per PC

App desktop **VoiceStudio** (ex OmniVoice Studio) per Windows 10/11 a 64 bit.

## Installazione veloce

1. Apri la pagina [omnivoice-pc/index.html](index.html) e premi **Scarica OmniVoice per Windows**.
2. Esegui il file `VoiceStudio_0.5.0_x64_en-US.msi`.
3. Nel menu Start cerca **VoiceStudio**.

Installer ufficiale: [VoiceStudio v0.5.0 MSI](https://github.com/debpalash/VoiceStudio/releases/download/v0.5.0/VoiceStudio_0.5.0_x64_en-US.msi)

## Installazione automatica

Metti `Installa-OmniVoice.bat` e `Installa-OmniVoice.ps1` nella stessa cartella, poi fai doppio clic sul `.bat`. Lo script scarica l’MSI ufficiale, verifica lo SHA256 e avvia `msiexec`.

Requisiti: Windows 10/11 x64, circa 10 GB liberi. GPU NVIDIA opzionale.
